The third article I ever wrote for this blog was about Azure CLI. It was called "[Goodbye Azure Portal, Welcome Azure CLI"](https://techwatching.dev/posts/welcome-azure-cli) and it discussed how great was Azure CLI to interact with Azure resources, and how to use it to be more productive with Azure. It was in 2019, at that time the original Azure CLI v1 (formerly known as `azure-xplat-cli`) had long been retired, and the Azure CLI v2 was the modern tool written in Python to interact with Azure on the command line.

Fast forward to today, the Azure CLI has continued to evolve and improve, but there was a need for a more modern, extensible, and user-friendly command-line experience that could better integrate with the growing ecosystem of Azure services.
